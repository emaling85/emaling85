### Hi, I'm emaling 👋

I build small, focused desktop tools that remove friction from everyday work: quick capture, note-taking and trading.

**Currently working on**

- 📝 **[CtrlNote](https://github.com/emaling85/CtrlNote)** — a Windows tray app that saves quick notes into Obsidian from a global hotkey: text, offline voice (Whisper), drawings and screenshots.
- 📈 **CtrlNote Trader** — the same app with a 20-second trading journal for Solana memecoins: live PnL, setups, mistakes and an auto-generated stats dashboard.
